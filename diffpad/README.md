# diffpad

2 つのテキストを左右に並べて、その差異をその場で表示する、高速・軽量・シンプルな比較用テキストパッドです。  
macOS / Windows 対応。

- 左右のペインに貼り付けるだけで、差異のある行と文字に色が付きます
- 差異を表示したまま、どちらのペインもそのまま編集できます
- 差異の表示は「行単位」と「文字単位」から選べます
- 書いた内容は自動的に引き継がれ、次回起動するとそのまま続きから使えます
- 完全にオフラインで動作します。どこにも送信しません
- 起動は速く、閉じると終了します。常駐しません
- ライト / ダークテーマ対応

## 動作環境

- macOS 11 以降 (Apple Silicon のみ)
- Windows 11 (x64 のみ)

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases/latest) の `diffpad-v<version>` から、お使いの OS 向けのファイルをダウンロードしてください。

- macOS: `diffpad_<version>_aarch64.dmg`
  - 開いて `diffpad.app` を「アプリケーション」フォルダへ入れます
- Windows: `diffpad_<version>_x64-setup.exe`
  - 実行するとインストーラが起動します。インストーラの案内に従ってください

### macOS で「壊れているため開けません」と表示される場合

コード署名・公証を行っていないため、ダウンロードした `.app` は Gatekeeper に拒否されます。  
「"diffpad.app" は壊れているため開けません。ゴミ箱に入れる必要があります。」と表示されますが、ファイルは壊れていません。ダウンロード時に付与される `com.apple.quarantine` 属性が原因です。

`.app` を「アプリケーション」フォルダに移したうえで、次のコマンドで属性を外してください。

```sh
xattr -dr com.apple.quarantine /Applications/diffpad.app
```

この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すとインストールを続けられます。

この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

## 使い方

ウィンドウは左右 2 つのペインに分かれています。左に比較元のテキスト、右に比較先のテキストを貼り付けると、
2 つの間で異なる箇所に色が付きます。左のペインでは赤、右のペインでは緑です。両方にある行は左右で同じ高さに
並び、片方にしかない行の向かいには斜線の空きが入ります。

どちらのペインもそのまま編集できます。差異は入力に合わせてその場で更新されます。

ステータスバー左下に、差異が何箇所あるかが表示されます。

### 差異の表示単位

ステータスバー右下のドロップダウンで切り替えます。

| 表示単位 | 色が付く範囲 |
|---|---|
| 行単位 | 差異のある行 |
| 文字単位 | 差異のある行に加えて、その行の中で異なる文字。異なる文字の前後は、単語のまとまりまで広げて色付けします |

この設定は次回起動時に引き継がれます。

### 差異の間を移動する

ステータスバー左下の「差異 N 箇所」の右にある `∧` `∨` のボタン、または `F7` / `Shift + F7` (macOS では `⇧ F7`)で、
差異を 1 つずつ辿れます。最後の差異の次は最初の差異に戻ります。移動するのは、最後にカーソルを置いていた側のペインです。

### 環境設定

以下の方法で環境設定画面が開きます。

| 方法 | macOS | Windows |
|---|---|---|
| ステータスバー右下の歯車 | ○ | ○ |
| メニューバー `diffpad` → `Preferences…` | ○ | — |
| キーボードショートカット | ⌘ , | Ctrl + , |

テーマ、フォント、フォントの太さ、フォントサイズ、タブ幅を変更できます。設定は両方のペインに適用され、次回起動時に引き継がれます。

### ウィンドウを常に手前に表示する

ステータスバー右下のピンのボタンを押すと、ウィンドウが他のウィンドウより手前に固定されます。  
この設定は次回起動時に引き継がれます。

### キーボードショートカット

| 操作 | macOS | Windows |
|---|---|---|
| 元に戻す | ⌘ Z | Ctrl + Z |
| やり直す | ⌘ ⇧ Z | Ctrl + Shift + Z |
| 次の差異 / 前の差異 | F7 / ⇧ F7 | F7 / Shift + F7 |
| 環境設定を開く | ⌘ , | Ctrl + , |
| フォントを大きく / 小さく | ⌘ = / ⌘ - | Ctrl + = / Ctrl + - |
| フルスクリーン切替 | ⌃ ⌘ F | F11 |
| 閉じる(= 終了) | ⌘ W | Ctrl + W |
| 終了 | ⌘ Q | Ctrl + Q / Alt + F4 |
| 環境設定を閉じる | Esc | Esc |

元に戻す / やり直すは、最後にカーソルを置いていた側のペインに対して働きます。

## 制限事項

- 自動アップデートはありません。更新するときは新しいバージョンを同じ手順で入れ直してください
- 配布物はコード署名・公証をしていません
- ウィンドウ位置は記憶しません
- 非常に大きい、または内容の大きく異なる 2 つのテキストでは、差異の計算を途中で切り上げ、大まかな色付けになることがあります
