# てなブク

はてなブックマークを読むための、iPhone 用の非公式アプリです。作者が自分で使うために作っています。

- カテゴリー別のホットエントリーを一覧できる
- 記事をアプリの中のブラウザで読める
- エントリーごとのコメントを、人気順と新着順で読める
- はてな側の仕様が変わって読み込めなくなったときは、画面に赤い表示が出る

## 動作環境

- iPhone（iOS 17 以降）

## インストール

App Store では配布していません。Mac の Xcode でビルドして、自分の iPhone に入れます。手順は [DEVELOPMENT.md](./DEVELOPMENT.md) にあります。

## 使い方

起動すると、総合のホットエントリーが表示されます。右上のボタンでカテゴリーを切り替えられます。

エントリーをタップすると、記事がアプリの中のブラウザで開きます。

ブラウザのバーには、次のボタンがあります。

- 「ブコメを見る」: そのエントリーのコメントを表示します。「人気」と「新着」で並び順を切り替えられます。「Safari で開く」を押すと、記事を Safari で開きます
- 「ブクマする」: まだ使えません
- 「共有」: 表示中のページを共有します

一覧を下に引くと、読み込み直します。

### 赤い表示が出たとき

「はてな側の仕様が変わった可能性があります」と赤く表示されたら、はてなの返す内容がアプリの想定と変わっています。時間をおいても直らない場合は、アプリの修正が必要です。

## できないこと

- ログイン、ブックマークの追加・編集・削除、スターはまだ使えません
- 過去のホットエントリーの検索はまだ使えません
- 人気順のコメントは、はてなが公式に提供していない方法で読み込んでいます。予告なく読めなくなることがあります
