# てなブク

はてなブックマークを読むための、iPhone 用の非公式アプリです。作者が自分で使うために作っています。

- カテゴリー別のホットエントリーを一覧できる
- お気に入りのユーザーと関心ワードから選ばれた、自分だけのホットエントリー（マイホットエントリー）を読める
- 記事をアプリの中のブラウザで読める
- 一度開いた記事は、一覧でタイトルが薄く表示される
- 見たくない記事を、ドメインや URL、タイトルのキーワードでミュートして一覧から隠せる。ワイルドカードと正規表現で書ける
- エントリーごとの注目コメントと新着コメントを読める
- はてなにログインして、記事をブックマークできる。コメント、タグ、非公開を付けられ、あとから編集や削除もできる
- 自分のブックマークを、非公開のものも含めて一覧できる。タイトル、本文、URL、コメントから探せる
- はてな側の仕様が変わって読み込めなくなったときは、画面に赤い表示が出る

## 動作環境

- iPhone（iOS 17 以降）

## インストール

App Store では配布していません。Mac の Xcode でビルドして、自分の iPhone に入れます。手順は [DEVELOPMENT.md](./DEVELOPMENT.md) にあります。

## 使い方

起動すると、総合のホットエントリーが表示されます。右上のボタンでカテゴリーを切り替えられます。

エントリーをタップすると、記事がアプリの中のブラウザで開きます。

ブラウザのバーには、次のボタンがあります。

- 「ブコメを見る」: そのエントリーのコメントを表示します。「注目」と「新着」で切り替えられます。「注目」には、はてなのエントリーページの注目コメントと同じものが並びます。「Safari で開く」を押すと、記事を Safari で開きます
- 「ブクマする」: ブックマークの画面を開きます
- 「共有」: 表示中のページを共有します

一覧を下に引くと、読み込み直します。

### ブックマークする

先に、一覧の設定で「はてなでログイン」を押し、はてなにログインします。

ブックマークの画面は、ブラウザとコメントの画面の「ブクマする」で開きます。一覧のエントリーを右にスワイプしても開けます。すでにブックマークしている記事では、前に保存した内容が入っていて、そのまま書き換えたり削除したりできます。

タグは 10 個まで付けられます。入力欄の下には、これまでに使ったタグが並び、入力した文字で絞り込まれます。タップすると追加され、付けたタグをタップすると外れます。

「ログインし直してください」と出たら、はてな側でログインが無効になっています。表示されるボタンか設定から、もう一度ログインします。

### 自分のブックマークを見る

一覧の右上の「マイブックマーク」を押すと、自分のブックマークが新しい順に並びます。下までスクロールすると、続きを読み込みます。使うには、先にはてなにログインしておきます。

2 回目からは、前に読み込んだ一覧がすぐに出ます。最新の状態にするには、一覧を下に引っ張ります。一覧の上に、いつ読み込んだものかが出ます。

さかのぼれるのは、新しいほうからおよそ 1 万件までです。それより古いブックマークは、検索すると見つかります。

上の検索欄に言葉を入れて検索すると、タイトル、本文、URL、コメントにその言葉を含むブックマークだけが並びます。空白で区切ると、すべての言葉を含むものを探します。検索欄を空にすると、一覧に戻ります。

ブックマークをタップすると、記事がアプリの中のブラウザで開きます。右にスワイプして「編集」を押すと、ブックマークの画面が開きます。

ブックマークしてすぐの記事は、一覧にも検索にもしばらく出ないことがあります。

### マイホットエントリーを読む

右上のボタンでカテゴリーを「マイホットエントリー」に切り替えます。

「Web でのログインが必要です」と表示されたら、「はてなの Web にログイン」を押し、はてなにログインします。ブックマークに使うログインとは別に、もう一度ログインが要ります。一覧の設定の「はてなの Web」からも、ログインとログアウトができます。

並ぶ記事は、お気に入りのユーザーと関心ワードで決まります。どちらもはてなの Web で設定します。どちらも設定していないと、記事は並びません。

### ミュートする

一覧のエントリーを左にスワイプして「ミュート」を押すと、ミュートの画面が開きます。そのエントリーのドメインが入っているので、そのまま保存すれば、同じドメインの記事が一覧に出なくなります。「タイトル」を選ぶと、タイトルのキーワードでミュートできます。

保存したミュートは、一覧の設定の「ミュートの条件」で確かめられます。タップすると編集でき、左にスワイプすると削除できます。

### 赤い表示が出たとき

「はてな側の仕様が変わった可能性があります」と赤く表示されたら、はてなの返す内容がアプリの想定と変わっています。時間をおいても直らない場合は、アプリの修正が必要です。

## できないこと

- スターはまだ使えません
- 過去のホットエントリーの検索はまだ使えません
- 注目コメントとマイホットエントリーは、はてなが公式に提供していない方法で読み込んでいます。予告なく読めなくなることがあります
