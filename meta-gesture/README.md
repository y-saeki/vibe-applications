# meta-gesture

右ボタンを押したままマウスを動かす「ジェスチャー」で、アプリの操作を呼び出す Windows・macOS 用アプリです。
同じジェスチャーに、アプリごとに違うキーを割り当てられます。たとえば `↓→` を「右側のタブを閉じる」と決めておけば、どのブラウザでも同じジェスチャーで同じ操作ができます。

- 「ブラウザ」のようなセットにアプリをまとめ、セットごとにコマンドとジェスチャーを登録できます
- コマンドで送るキーはセットのアプリすべてに同じものも、アプリごとに違うものも設定できます
- すべてのアプリに効く「共通」セットがあります
- ジェスチャーを登録していないアプリでは、右ボタンはふだんどおりに動きます
- 認識したコマンドの名前を、ポインタの横に短く表示します

## 動作環境

- Windows 10 / Windows 11 (x64 のみ)
- macOS 13 以降 (Apple シリコンのみ。Intel プロセッサの Mac では動きません)

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases) の `meta-gesture-v<version>` から、お使いの OS 向けのファイルをダウンロードしてください。

- Windows: `meta-gesture_<version>_x64-setup.exe`
  - 実行するとインストーラが起動します。インストーラの案内に従ってください。管理者権限は不要です
- macOS: `meta-gesture_<version>_macos-arm64.dmg`
  - 開いて `meta-gesture.app` を「アプリケーション」フォルダへ入れます

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すと続けられます。

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### macOS で「壊れているため開けません」と表示される場合

公証を行っていないため、ダウンロードした `.app` の実行は Gatekeeper に拒否されます。  
`.app` を「アプリケーション」フォルダに移したうえで、次のコマンドで隔離属性を外してください。

```sh
xattr -dr com.apple.quarantine /Applications/meta-gesture.app
```

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### macOS でアクセシビリティの許可を求められた場合

meta-gesture がマウスの操作を受け取ってキーを送るには、アクセシビリティの許可が必要です。  
初めて起動したときに許可を求められたら「システム設定を開く」を押し、「アクセシビリティ」の一覧で meta-gesture をオンにしてください。
オンにすると、起動し直さなくてもジェスチャーが使えるようになります。

## 使い方

タスクトレイのアイコン(macOS ではメニューバーのアイコン)から設定画面を開きます。

### ジェスチャーを登録する

1. 「セット」の「追加」でセットを作り、「セット名」に名前を入れます
2. 「アプリ」の「起動中のアプリから追加」で、セットに入れるアプリを選びます。起動していないアプリは「参照...」(macOS では「選択...」)から選びます
3. 「コマンド」の「追加」でコマンドを作り、「コマンド名」に名前を入れます
4. 「ジェスチャー」の矢印のボタンを、描く順に押します
5. 「送るキー」の「変更」を押し、送りたいキーの組み合わせを押します
6. 「保存して閉じる」を押します

「送るキー」のいちばん上の行「セットの既定」は、セットのどのアプリにも送るキーです。その下に並ぶアプリの行にキーを設定すると、そのアプリにはそちらを送ります。

すべてのアプリで使いたいコマンドは「共通」セットに登録します。セットのコマンドと共通セットのコマンドに同じジェスチャーがあるときは、セットのコマンドが優先されます。

### ジェスチャーを描く

右ボタンを押したまま上下左右に動かし、ボタンを離します。ほとんど動かさずに離すと、ふだんの右クリックになります。

### 設定を別の PC に移す

設定画面の「エクスポート...」で、セットとコマンドをファイルに書き出せます。
移したい PC の設定画面で「インポート...」からそのファイルを選ぶと、設定がファイルの内容に置き換わります。「保存して閉じる」を押すと確定します。
Windows で書き出したファイルは macOS では読み込めません。macOS で書き出したファイルも Windows では読み込めません。

### 終了する

Windows では通知領域のアイコンを右クリックし、「終了」を選びます。macOS ではメニューバーのアイコンをクリックし、「終了」を選びます。

### 更新・アンインストール

更新するときは、新しいバージョンのインストーラを実行してください。起動中の meta-gesture は自動で終了し、上書きされます。  
設定はそのまま引き継がれます。

アンインストールは Windows の「設定」→「アプリ」→「インストールされているアプリ」から meta-gesture を選んで行います。

macOS で更新するときは、meta-gesture を終了してから、新しい `.dmg` の `meta-gesture.app` を「アプリケーション」フォルダへ入れて置き換え、
インストールのときと同じコマンドで隔離属性を外してください。設定はそのまま引き継がれます。  
リリースノートで案内があったときは、更新のあとにジェスチャーが効かなくなります。一度だけ、「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」の一覧で meta-gesture を選んで「−」で削除し、meta-gesture を起動し直して許可し直してください。

macOS でアンインストールするときは、meta-gesture を終了してから「アプリケーション」フォルダの meta-gesture をゴミ箱へ移します。
設定も消すときは、`~/Library/Application Support/meta-gesture` フォルダを削除してください。

## 制限事項

- アプリに既定のショートカットがない操作(Chrome の「右側のタブを閉じる」など)は、そのままでは送れません。アプリの側でショートカットを付けられる操作なら、そのショートカットを送るキーに設定してください
- ジェスチャーを登録したアプリでは、右ボタンを押したままのドラッグが使えなくなります
- Windows: 管理者として実行されているアプリには、meta-gesture も管理者として実行しているときにしかキーを送れません
- 記号のキーは `Oem4` のような名前で表示されます
- 自動アップデートはありません。更新するときは新しいインストーラを実行してください
- Windows の配布物はコード署名をしていません。macOS の配布物は公証をしていません
