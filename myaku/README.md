# myaku

プロセスごとの CPU・メモリ・ネットワークの使用量を、直近 1 分のグラフで並べて見せる macOS・Windows 用アプリです。  
メニューバー(Windows では通知領域)に常駐します。  
開発が終了したと思われる [Vitals](https://github.com/hmarr/vitals) と同等の機能を、macOS と Windows の両方で使えるように作り直しました。

- アクティビティモニタやタスクマネージャーは今の使用量しか見せませんが、myaku は直近 60 秒の推移をプロセスごとのグラフで見せます
- 起動している間は裏で記録を続けるので、開いた時点で直近 1 分間の様子が分かります。いわゆるプチフリーズが起きた時など、フリーズから復旧してから myaku を見れば犯人がわかります
- 直近 1 分の合計が多い順に、上位 20 プロセスを並べます。並べる基準は CPU・メモリ・ネットワーク(受信・送信)から選べます
- 終了したプロセスも、グラフが流れ切るまでは引き続き表示されます
- myaku自身がPCに負荷を与えないよう、軽量・高速に動作します

## 動作環境

- macOS 13 以降 (Apple シリコンのみ。Intel プロセッサの Mac では動きません)
- Windows 10 / Windows 11 (x64 のみ)

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases) の `myaku-v<version>` から、お使いの OS 向けのファイルをダウンロードしてください。

- Windows: `myaku_<version>_x64-setup.exe`
  - 実行するとインストーラが起動します。インストーラの案内に従ってください。管理者権限は不要です
- macOS: `myaku_<version>_macos-arm64.dmg`
  - 開いて `myaku.app` を「アプリケーション」フォルダへ入れます

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すと続けられます。

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### macOS で「壊れているため開けません」と表示される場合

公証を行っていないため、ダウンロードした `.app` の実行は Gatekeeper に拒否されます。  
`.app` を「アプリケーション」フォルダに移したうえで、次のコマンドで隔離属性を外してください。

```sh
xattr -dr com.apple.quarantine /Applications/myaku.app
```

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

## 使い方

メニューバーのアイコン(Windows では通知領域のアイコン)をクリックすると一覧が開きます。  
見出しの右の矢印で、並べる基準を切り替えます。Windows ではキーボードの `←` `→` でも切り替えられます。

グラフは 1 段が CPU 1 コア分です。1 コアを超えた分は同じグラフに色を濃くして重ね、4 コア分まで描きます。  
右端の数値は最新の値で、CPU は 1 コアを 100% とした割合です。

### ネットワークの使用量を見る(macOS)

メニューの「ネットワークの使用量を測る」をオンにすると、並べる基準に「ネットワーク(受信)」と「ネットワーク(送信)」が加わります。

### ログイン時に起動する

macOS ではメニューの「ログイン時に開く」、Windows では通知領域のアイコンを右クリックして「サインイン時に起動」をオンにします。

### 終了する

macOS ではメニューバーのアイコンをクリックし、「myaku を終了」を選びます。  
Windows では通知領域のアイコンを右クリックし、「myaku を終了」を選びます。

### 更新・アンインストール

Windows で更新するときは、新しいバージョンのインストーラを実行してください。起動中の myaku は自動で終了し、上書きされます。  
アンインストールは、Windows の「設定」→「アプリ」→「インストールされているアプリ」から myaku を選んで行います。

macOS で更新するときは、myaku を終了してから、新しい `.dmg` の `myaku.app` を「アプリケーション」フォルダへ入れて置き換え、インストールのときと同じコマンドで隔離属性を外してください。  
アンインストールするときは、myaku を終了してから「アプリケーション」フォルダの myaku をゴミ箱へ移します。

## 制限事項

- Windows ではネットワークの使用量を測れません。管理者権限なしでプロセスごとの通信量を得る手段を、Windows が用意していないためです
- Windows 10 と Windows 11 21H2 では、一覧の背景は半透明にならず、単色になります
- 自動アップデートはありません
- Windows の配布物はコード署名をしていません。macOS の配布物は公証をしていません
