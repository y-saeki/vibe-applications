# eleven-zip

![](icon.svg)

エクスプローラーから書庫をすばやく展開する Windows 用アプリです。展開には 7-Zip を使います。

- 右クリックメニューやダブルクリックで、zip・7z・rar・tar・gz・xz・zst・lzh・cab・iso など 7-Zip が読める書庫を展開
- 展開が終わると、展開先をエクスプローラーで開く。展開した書庫をごみ箱に入れることもできる
- 中身が 1 つのフォルダーだけの書庫は、フォルダーを二重にせずに展開
- 7-Zip を別途インストールする必要はなく、新しい版が出ると自動で更新
- Windows 11 の設定アプリと同じ見た目の設定画面

## 動作環境

- Windows 10 (1809 以降) / Windows 11 (x64 のみ)
- 7-Zip の取得と更新にインターネット接続が必要です。7-Zip は作者が GitHub で公開しているもの([ip7z/7zip](https://github.com/ip7z/7zip/releases))を取得します

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases) の `eleven-zip-v<version>` から
`eleven-zip_<version>_x64-setup.exe` をダウンロードして実行し、インストーラの案内に従ってください。
管理者権限は不要です。

インストールの最後に設定画面が開き、7-Zip を取得します。

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すと続けられます。

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

## 使い方

### 展開する

書庫を右クリックし、「eleven-zip で展開」を選びます。  
Windows 11 では、右クリックメニューの「その他のオプションを確認」の中にあります。

書庫と同じフォルダーに展開され、終わるとエクスプローラーで開きます。
パスワード付きの書庫では、7-Zip のウィンドウでパスワードを入力します。

### ダブルクリックで展開する

書庫をダブルクリックで展開するには、eleven-zip を既定のアプリにします。

1. 書庫を右クリックし、「プログラムから開く」→「別のプログラムを選択」を選びます
2. 一覧から eleven-zip を選び、「常に使う」を押します

拡張子ごとに設定が必要です。Windows 11 では、設定画面の「既定のアプリ」から Windows の設定を開くと、
eleven-zip が扱う拡張子の一覧から選べます。

### 設定を変える

スタートメニューの eleven-zip から設定画面を開きます。切り替えた設定はすぐに反映されます。

### 更新・アンインストール

eleven-zip を更新するときは、新しいバージョンのインストーラを実行してください。設定はそのまま引き継がれます。

アンインストールは、Windows の「設定」→「アプリ」→「インストールされているアプリ」から eleven-zip を選んで行います。
右クリックメニューと関連付け、eleven-zip が取得した 7-Zip も一緒に削除されます。

## 制限事項

- 展開専用です。圧縮はできません
- `.tar.gz` などは 1 回目の展開で `.tar` になります。もう一度展開してください
- 複数の書庫を選んで展開すると、書庫ごとに 7-Zip のウィンドウが開き、それぞれの展開先がエクスプローラーで開きます
- eleven-zip 自体の自動更新はありません。更新するときは新しいインストーラを実行してください
- 配布物はコード署名をしていません
