# draftpad

ファイルや保存の概念を持たない、高速・軽量・シンプルな下書き用エディタです。  
macOS / Windows 対応。

- 書いた内容は自動的に引き継がれ、次回起動するとそのまま続きから書けます
- 起動は速く、閉じると終了します。常駐しません
- 20 言語のシンタックスハイライト、正規表現対応の検索・置換、Vim モード
- 2 つのテキストを左右に並べて、差異をその場で色付けして比較できます
- ライト / ダークテーマ対応

## 動作環境

- macOS 11 以降 (Apple Silicon のみ)
- Windows 11 (x64 のみ)

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases/latest) の `draftpad-v<version>` から、お使いの OS 向けのファイルをダウンロードしてください。

- macOS: `draftpad_<version>_aarch64.dmg`
  - 開いて `draftpad.app` を「アプリケーション」フォルダへ入れます
- Windows: `draftpad_<version>_x64-setup.exe`
  - 実行するとインストーラが起動します。インストーラの案内に従ってください

### macOS で「壊れているため開けません」と表示される場合

コード署名・公証を行っていないため、ダウンロードした `.app` は Gatekeeper に拒否されます。  
「"draftpad.app" は壊れているため開けません。ゴミ箱に入れる必要があります。」と表示されますが、ファイルは壊れていません。ダウンロード時に付与される `com.apple.quarantine` 属性が原因です。

`.app` を「アプリケーション」フォルダに移したうえで、次のコマンドで属性を外してください。

```sh
xattr -dr com.apple.quarantine /Applications/draftpad.app
```

この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すとインストールを続けられます。

この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

## 使い方

ウィンドウ全体がエディタです。書いた内容をコピーして貼り付け先へ持っていく、という使い方を想定しています。  
コピー時はプレーンテキストのみをクリップボードに書き出すため、貼り付け先に書式が混入しません。

### 常に手前に表示

ステータスバー右下のピンのボタンを押すと、ウィンドウが他のウィンドウより手前に固定されます。  
この設定は次回起動時に引き継がれます。

### 検索・置換

`⌘ F` / `Ctrl + F` で検索・置換パネルが開きます。

検索欄では「大文字小文字を区別」と「正規表現」のオプションを使用できます。  
この設定は次回起動時に引き継がれます。

正規表現モードでは、置換文字列に `$1` `$2` … と `$&` が使えます。

### シンタックスハイライト

ウィンドウ上部のバー左端のドロップダウンから、文章全体のシンタックスハイライトに使用する言語を選択できます。  
Markdown のフェンスコードブロック(```js など)を使用した場合、ブロック内のみ指定言語でハイライトされます。

対応言語は以下の通りです。

- Markdown
- plaintext
- YAML
- Batch
- HTML
- XML
- Dockerfile
- JavaScript
- TypeScript
- Ruby
- Go
- CSS
- LESS
- SCSS
- Solidity
- MySQL
- pgSQL
- PHP
- PowerShell
- Rust

### テキストを比較する

ウィンドウ上部のバー右端のボタン、または `⌘ \` / `Ctrl + \` で、右側にもう 1 つペインが開き、ウィンドウの幅が倍になります。  
右のペインには左と同じテキストが入った状態で始まるので、比べたいテキストを貼り付けるだけで、2 つの間で異なる箇所に色が付きます。
左のペインでは赤、右のペインでは緑です。両方にある行は左右で同じ高さに並び、片方にしかない行の向かいには斜線の空きが入ります。

どちらのペインもそのまま編集できます。差異は入力に合わせてその場で更新されます。

右のペインのバーには、右のペインで増えた行数と減った行数が `+N` `−N` で表示されます。  
差異の表示単位は、同じバーの左端のドロップダウンで切り替えます。

| 表示単位 | 色が付く範囲 |
|---|---|
| 行単位 | 差異のある行 |
| 文字単位 | 差異のある行に加えて、その行の中で異なる文字。異なる文字の前後は、単語のまとまりまで広げて色付けします |

この設定は次回起動時に引き継がれます。

言語やフォントなどの設定は、すべて両方のペインに適用されます。検索・置換パネルはカーソルのあるペインに開き、
「大文字小文字を区別」と「正規表現」の設定は両方のペインで共通です。

比較を終えるには、各ペインのバー右端の × ボタンを押すか、`⌘ W` / `Ctrl + W` でカーソルのあるペインを閉じます。
押したペインが消えて、もう一方がそのまま 1 ペインの下書きとして残ります。確認は出ません。ウィンドウの幅は元に戻ります。

フルスクリーン中はウィンドウの大きさを変えず、画面を左右に 2 分割します。  
2 ペインのまま閉じると、次回も 2 ペインで、両方のテキストが引き継がれた状態で起動します。

## 制限事項

- 自動アップデートはありません。更新するときは新しいバージョンを同じ手順で入れ直してください
- 配布物はコード署名・公証をしていません
- ウィンドウ位置は記憶しません
- 比較のペインを開いたり閉じたりすると、それまでの「元に戻す」の履歴は消えます
- 非常に大きい、または内容の大きく異なる 2 つのテキストでは、差異の計算を途中で切り上げ、大まかな色付けになることがあります
