# draftpad

ファイルや保存の概念を持たない、高速・軽量・シンプルな下書き用エディタです。  
macOS / Windows 対応。

- 書いた内容は自動的に引き継がれ、次回起動するとそのまま続きから書けます
- 起動は速く、閉じると終了します。常駐しません
- 20 言語のシンタックスハイライト、正規表現対応の検索・置換、単語補完、Vim モード
- 空白文字 (スペース・全角スペース・タブ) を、控えめな印で表示できます
- インデントの段ごとに、控えめな縦線を引けます
- ライト / ダークテーマ対応

## 動作環境

- macOS 11 以降 (Apple Silicon のみ)
- Windows 11 (x64 のみ)

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases/latest) の `draftpad-v<version>` から、お使いの OS 向けのファイルをダウンロードしてください。

- macOS: `draftpad_<version>_aarch64.dmg`
  - 開いて `draftpad.app` を「アプリケーション」フォルダへ入れます
- Windows: `draftpad_<version>_x64-setup.exe`
  - 実行するとインストーラが起動します。インストーラの案内に従ってください

### macOS で「壊れているため開けません」と表示される場合

コード署名・公証を行っていないため、ダウンロードした `.app` は Gatekeeper に拒否されます。  
「"draftpad.app" は壊れているため開けません。ゴミ箱に入れる必要があります。」と表示されますが、ファイルは壊れていません。ダウンロード時に付与される `com.apple.quarantine` 属性が原因です。

`.app` を「アプリケーション」フォルダに移したうえで、次のコマンドで属性を外してください。

```sh
xattr -dr com.apple.quarantine /Applications/draftpad.app
```

この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すとインストールを続けられます。

この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

## 使い方

ウィンドウ全体がエディタです。書いた内容をコピーして貼り付け先へ持っていく、という使い方を想定しています。  
コピー時はプレーンテキストのみをクリップボードに書き出すため、貼り付け先に書式が混入しません。  
貼り付けも常にプレーンテキストとして行われます。他のアプリで「プレーンテキストとして貼り付け」に割り当てられていることの多い `⌘ ⇧ V` / `Ctrl + Shift + V` でも、同じように貼り付けられます。

### 右クリックメニュー

エディタの上で右クリックすると、次のメニューが開きます。検索・置換パネルや環境設定パネルの入力欄でも同じです。

- 元に戻す / やり直す
- 切り取り / コピー / 貼り付け
- すべてを選択
- 検索・置換

ステータスバーなど、文字を入力しない場所ではメニューは出ません。

### 環境設定

以下の方法で環境設定画面が開きます。

| 方法 | macOS | Windows |
|---|---|---|
| ステータスバー右下の歯車 | ○ | ○ |
| メニューバー `draftpad` → `環境設定…` | ○ | — |
| タスクバーアイコンの右クリックメニュー → `設定` | — | ○ |
| キーボードショートカット | ⌘ , | Ctrl + , |

### 空白文字を表示する

環境設定の「空白文字を表示」を入れると、本文の空白文字に薄い印が付きます。

| 文字 | 印 |
|---|---|
| スペース | 中央の点 |
| 全角スペース | 中央の点。スペースより広い間隔で並びます |
| タブ | 右向きの矢印 |

印は本文より一段淡く、文字幅も行の高さも変えません。フォントサイズに合わせて大きさが変わります。

この設定は次回起動時に引き継がれます。

### インデントガイドを表示する

環境設定の「インデントガイドを表示」を入れると、インデントの段ごとに薄い縦線が引かれます。1 段の幅は
「タブ幅」の設定に従い、その幅に満たない端数には線が付きません。

縦線は行をまたいでも途切れません。ブロックの途中にある空の行にも、前後の行と同じだけ続きます。

この設定は次回起動時に引き継がれます。

### ウィンドウを常に手前に表示する

ステータスバー右下のピンのボタンを押すと、ウィンドウが他のウィンドウより手前に固定されます。  
この設定は次回起動時に引き継がれます。

### 検索・置換

`⌘ F` / `Ctrl + F` で検索・置換パネルが開きます。

検索欄には `Aa` (大文字小文字を区別)と `.*` (正規表現)のオプションを使用できます。  
これらのオプション設定は次回起動時に引き継がれます。

正規表現モードでは、置換文字列に `$1` `$2` … と `$&` が使えます。(例: `(\d+)` → `$1円`)

### シンタックスハイライト

以下の言語のシンタックスハイライトに対応しています。

- Markdown
- plaintext
- YAML
- Batch
- HTML
- XML
- Dockerfile
- JavaScript
- TypeScript
- Ruby
- Go
- CSS
- LESS
- SCSS
- Solidity
- MySQL
- pgSQL
- PHP
- PowerShell
- Rust

ウィンドウ右下のドロップダウンから、文章全体のシンタックスハイライトに使用する言語を選択できます。  
Markdown のフェンスコードブロック(```js など)を使用した場合、ブロック内のみ指定文法でハイライトされます。

### キーボードショートカット

| 操作 | macOS | Windows |
|---|---|---|
| 貼り付け | ⌘ V / ⌘ ⇧ V | Ctrl + V / Ctrl + Shift + V |
| 元に戻す | ⌘ Z | Ctrl + Z |
| やり直す | ⌘ ⇧ Z | Ctrl + Shift + Z |
| 環境設定を開く | ⌘ , | Ctrl + , |
| 検索・置換 | ⌘ F | Ctrl + F |
| 次を検索 / 前を検索 | ⌘ G / ⌘ ⇧ G | F3 / Shift + F3 |
| フルスクリーン切替 | ⌃ ⌘ F | F11 |
| 閉じる(= 終了) | ⌘ W | Ctrl + W |
| 終了 | ⌘ Q | Ctrl + Q / Alt + F4 |
| 環境設定を閉じる | Esc | Esc |

## 制限事項

- 自動アップデートはありません。更新するときは新しいバージョンを同じ手順で入れ直してください
- 配布物はコード署名・公証をしていません
- ウィンドウ位置は記憶しません
