Mail Crew

Gmail の受信トレイを、1 通ずつのカードで読むメーラーです。

どちらも Google Cloud で作ったものを使います。作り方は README にあります。

ブラウザで Google にログインしてください。完了すると、ここに受信トレイが開きます。

受信トレイ

受信トレイは空です

新しいメールが届いたら、再読み込みで表示されます。

設定

アカウント

    別の OAuth クライアントでログインする

    空欄のままなら、最初のアカウントと同じクライアントを使います。

    ブラウザで、追加する Google アカウントにログインしてください。

    ビュー

    受信トレイの中を絞り込んだ一覧です。サイドバーの「受信トレイ」「あとで読む」の下に並びます。

      アカウント（選ばなければすべて）

      画像を常に表示する差出人

      ここにある差出人からのメールは、外部の画像を確認せずに読み込みます。削除すると、次からはメールごとに確認します。
