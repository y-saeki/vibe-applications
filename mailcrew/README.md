# Mail Crew

Gmail の受信トレイを、スレッドごとの縦長のカードにして横に並べて読むメーラーです。  
macOS / Windows 対応。

- 受信トレイのスレッドが 1 枚ずつのカードになり、新しいものから左に並びます。カードには本文がそのまま表示されます
- 複数の Gmail アカウントのメールを、1 本の列に新しい順で並べて読めます。アカウントや検索条件で絞り込んだビューも作れます
- カード下のボタンで、完了（既読にしてアーカイブ）、タグ付け、あとで読む、スターをワンクリックで済ませられます
- 最後のカードまで読んだら、「まとめて完了」で表示中のスレッドを一度に片付けて、次の 50 件に進めます
- メール本文の外部画像は、表示すると決めたメールと、常に表示すると決めた差出人のメールでだけ読み込みます。ほかのメールは、開いただけでは開封したことが送り主に伝わりません

## 動作環境

- macOS 11 以降 (Apple Silicon のみ)
- Windows 10 (1809 以降) / 11 (x64 のみ)
- Gmail のアカウントと、Google Cloud のプロジェクト（無料で作れます。作り方は「初回の準備」にあります）

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases) の `mailcrew-v<version>` から、お使いの OS 向けのファイルをダウンロードしてください。

- macOS: `Mail.Crew_<version>_aarch64.dmg`
  - 開いて `Mail Crew.app` を「アプリケーション」フォルダへ入れます
- Windows: `Mail.Crew_<version>_x64-setup.exe`
  - 実行するとインストーラが起動します。インストーラの案内に従ってください

### macOS で「壊れているため開けません」と表示される場合

コード署名・公証を行っていないため、ダウンロードした `.app` の実行は Gatekeeper に拒否されます。  
`.app` を「アプリケーション」フォルダに移したうえで、次のコマンドで隔離属性を外してください。

```sh
xattr -dr com.apple.quarantine "/Applications/Mail Crew.app"
```

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すとインストールを続けられます。

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

## 初回の準備

Mail Crew は Gmail に接続するための OAuth クライアントを、利用者自身の Google Cloud プロジェクトで作って使います。一度作れば、あとは起動するだけです。

1. [Google Cloud コンソール](https://console.cloud.google.com/)でプロジェクトを作ります
2. 「API とサービス」の「ライブラリ」で **Gmail API** を有効にします
3. OAuth 同意画面（Google Auth Platform）を設定します
   - ユーザーの種類は「外部」にします
   - アプリ名とサポート用のメールアドレスは、自分で分かるものなら何でも構いません
   - テストユーザーに、Mail Crew で読む Gmail のアドレスをすべて追加します
4. 「クライアント」で OAuth クライアントを作ります。アプリケーションの種類は「**デスクトップ アプリ**」を選びます
5. 表示されたクライアント ID とクライアント シークレットを、Mail Crew の最初の画面に入力して「Google でログイン」を押します
6. ブラウザで Google のログイン画面が開きます。「Google はこのアプリを確認していません」と表示されたら、「続行」を選んで Gmail へのアクセスを許可します

同意画面の公開ステータスが「テスト」のままだと、7 日ごとにログインし直す必要があります。続けて使うなら、同意画面の「対象」で公開ステータスを「本番環境」に切り替えてください。確認の審査を受けていないアプリのままでも、自分のアカウントで使うぶんには、上の 6 の警告画面が出るだけです。

クライアント ID、クライアント シークレット、ログイン情報は、macOS ではキーチェーン、Windows では資格情報マネージャーに入ります。

## 使い方

起動すると、ログインしているすべてのアカウントの受信トレイから、新しいスレッドの順に最大 50 件がカードで並びます。カードの列はトラックパッドの横スクロールか、カードの見出しやボタンの上でのマウスホイールで左右に動かせます。

カード下のボタンを押すと、そのスレッドは受信トレイから外れ、カードの列からも消えます（スターだけは外れません）。

| ボタン | Gmail 上でどうなるか |
|---|---|
| 完了 | 既読にしてアーカイブ |
| タグ | 選んだラベルを付けてアーカイブ。名前を入力すると、新しいラベルも作れます |
| あとで読む | `SetAside` ラベルを付けてアーカイブ。ラベルがなければ最初に作ります |
| スター | スターを付ける / 外す |

「あとで読む」にしたメールは、サイドバーの「あとで読む」に並びます（Gmail では `SetAside` ラベルから読めます）。ここで「完了」か「タグ」を押すと、メールが「あとで読む」から外れます。

列の最後にある「まとめて完了」を押すと、表示中のスレッドをすべて既読にしてアーカイブし、受信トレイの次の 50 件を読み込みます。受信トレイが空になると、その旨が表示されます。

新しいメールは自動では読み込みません。画面右上の再読み込みボタンか、`⌘ R` / `Ctrl + R` で読み込みます。

### アカウントの追加と削除

サイドバーの下にある「設定」を開き、「Google でログインして追加」を押すと、ブラウザで Google のログイン画面が開きます。追加するアカウントでログインしてください。最初のアカウントと同じ OAuth クライアントを使うので、同意画面の公開ステータスが「テスト」なら、そのアドレスもテストユーザーに追加しておきます。別の Google Cloud プロジェクトのクライアントを使うときは、「別の OAuth クライアントでログインする」を開いて入力します。

設定でアカウントを削除すると、そのアカウントのログイン情報が Mail Crew から消えます。Gmail のメールはそのまま残ります。

### ビュー

画面左のサイドバーで、並べるメールを切り替えます。「受信トレイ」と「あとで読む」には、ログインしているすべてのアカウントのメールが並びます。

設定の「ビュー」で、アカウントと検索条件を選んだビューを作れます。作ったビューはサイドバーの「あとで読む」の下に並びます。検索条件は Gmail の検索ボックスと同じ書き方（`from:example.com`、`is:unread` など）で指定します。

### 本文の画像とリンク

外部の画像を使うメールでは、本文の上に「外部の画像を読み込んでいません」と出ます。「表示する」を押すと、そのメールだけ画像を読み込みます。「この差出人は常に表示」を押すと、同じ差出人（メールアドレス）からのメールでは、次から確認せずに画像を読み込みます。常に表示する差出人は設定の「画像を常に表示する差出人」で削除できます。本文中のリンクは既定のブラウザ（メールアドレスのリンクはメールアプリ）で開きます。

### アップデートしたあと

macOS では新しいバージョンを初めて起動したときに、キーチェーンへのアクセスを求めるダイアログが 1 回出ます。キーチェーンのパスワード（通常は Mac のログインパスワード）を入れて「常に許可」を選ぶと、次に更新するまでは出ません。

0.3 以前から 0.4 に更新したときだけは、ログインしているアカウントの数より 1 回多く出ます。

## 制限事項

- 読むことと、ラベルを付けて片付けることだけができます。送信・返信はできません
- ビューで絞り込めるのは受信トレイにあるメールだけです
- カードに表示されるのは、スレッドの最新の 1 通だけです（下書きを除く）
- 添付ファイルは数とファイル名（数にマウスを重ねると出ます）だけが分かり、開けません
- 本文中に埋め込まれた画像（`cid:` で参照されるもの）は表示されません
- 自動アップデートはありません。更新するときは新しいバージョンを同じ手順で入れ直してください
- 配布物はコード署名・公証をしていません
