# winwin

キーボードショートカット 1 つで、前面のウィンドウを決まった位置・大きさに並べ直す Windows 用ツールです。

- `Ctrl + Alt + ←` で左半分、`Ctrl + Alt + U` で左上 4 分の 1 のように、よく使う配置が最初から登録されています
- 位置と大きさは画面に対する割合(50%)でもピクセル(800px)でも指定でき、自分用の配置を好きなだけ追加できます
- ウィンドウがあるモニターのタスクバーを除いた範囲に合わせて配置するので、複数モニターや拡大率の違うモニターでもそのまま使えます
- 常駐中は通知領域のアイコンだけで、ショートカットが押されるまで何もしません

## 動作環境

- Windows 10 (1703 以降) / Windows 11 (x64 のみ)

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases) の `winwin-v<version>` から
`winwin_<version>_x64-setup.exe` をダウンロードして実行し、インストーラの案内に従ってください。
管理者権限は不要です。

インストールせずに使う場合は、同じ Release の `winwin.exe` を好きなフォルダに置いて実行してください。

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラと `winwin.exe` は SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すと続けられます。

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

## 使い方

起動すると通知領域(タスクバー右端)にアイコンが出ます。動かしたいウィンドウを前面にした状態でショートカットを押すと、
そのウィンドウが登録した位置・大きさに移動します。最大化しているウィンドウは、最大化を解除してから配置します。

最初から登録されているショートカットは、`Ctrl + Alt` と矢印キーでの上下左右半分、`Enter` で画面いっぱい、`C` で中央、
`U` `I` `J` `K` で四隅、`D` `F` `G` で 3 分の 1、`E` `T` で 3 分の 2 です。

### 配置を追加・変更する

通知領域のアイコンをクリックすると設定画面が開きます(右クリックのメニューの「設定を開く」でも同じです)。
設定画面を開いている間、ショートカットは働きません。

配置は「基準位置」「幅・高さ」「ずらし幅」の組み合わせで決まります。

- 基準位置: ウィンドウを画面のどこに寄せるか(左上・上・右上・左・中央・右・左下・下・右下)
- 幅・高さ: `50%` のような割合か、`800px` のようなピクセル数。ピクセル数は拡大率 100% のときの大きさで、
  拡大率 150% のモニターでは 1.5 倍になります
- ずらし幅: 基準位置からさらに動かす量。右・下方向が正で、`-20px` のように負の値も使えます

たとえば「右下に 800×600 で、画面の端から少し離す」なら、基準位置を右下、幅 `800px`、高さ `600px`、
ずらし幅を横・縦とも `-16px` にします。ウィンドウが画面からはみ出す指定は、画面内に収まるように縮めて配置します。

ショートカットに Windows キーを含めるときは、ショートカット欄の左の「Win +」にチェックを入れてください。

### 終了する

通知領域のアイコンを右クリックし、「終了」を選びます。

### 更新・アンインストール

更新するときは、新しいバージョンのインストーラを実行してください。起動中の winwin は自動で終了し、上書きされます。
設定はそのまま引き継がれます。

アンインストールは、Windows の「設定」→「アプリ」→「インストールされているアプリ」から winwin を選んで行います。
途中でショートカットの設定も削除するかを聞かれます。

`winwin.exe` だけで使っている場合は、winwin を終了してからファイルを置き換えれば更新できます。やめるときは、
設定画面で「Windows へのサインイン時に winwin を起動する」のチェックを外して保存してから winwin を終了し、
`winwin.exe` と `%APPDATA%\winwin` フォルダを削除してください。

## 制限事項

- 管理者として実行されているウィンドウは、winwin も管理者として実行しているときにしか動かせません
- Windows や他のアプリケーションがすでに使っているショートカット(`Win + ←` など)は登録できません。
  登録できなかったものは起動時に通知でお知らせします
- アプリケーションによっては、最小サイズなどの都合で指定どおりの大きさにならないことがあります
- 自動アップデートはありません。更新するときは新しいインストーラを実行してください
- 配布物はコード署名をしていません
