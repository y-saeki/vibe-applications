# winwin

ウィンドウを決まった位置・大きさに配置する Windows・macOS 用アプリです。

- 任意のショートカットキー押下でウィンドウをリサイズ・再配置
- サイクルショートカット対応： 1 つのショートカットキーに複数の配置を割り当て可能
- キーストローク対応： `Ctrl+Shift` を押したまま `← , ↑` 連続入力のようなショートカットを割り当て可能
- 配置したウィンドウをタイトルバーでドラッグして動かすと、配置する前の大きさに戻る
- フィット対応： いちばん手前のウィンドウを避けて、空いている側いっぱいにウィンドウを広げる配置が可能
- リセット対応： winwin で配置したウィンドウを、配置する前の位置・大きさに戻すショートカットを登録可能

## 動作環境

- Windows 10 (1809 以降) / Windows 11 (x64 のみ)
- macOS 13 以降 (Apple シリコンのみ。Intel プロセッサの Mac では動きません)

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases) の `winwin-v<version>` から、お使いの OS 向けのファイルをダウンロードしてください。

- Windows: `winwin_<version>_x64-setup.exe`
  - 実行するとインストーラが起動します。インストーラの案内に従ってください。管理者権限は不要です
- macOS: `winwin_<version>_macos-arm64.dmg`
  - 開いて `winwin.app` を「アプリケーション」フォルダへ入れます

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すと続けられます。

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### macOS で「壊れているため開けません」と表示される場合

公証を行っていないため、ダウンロードした `.app` の実行は Gatekeeper に拒否されます。  
`.app` を「アプリケーション」フォルダに移したうえで、次のコマンドで隔離属性を外してください。

```sh
xattr -dr com.apple.quarantine /Applications/winwin.app
```

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### macOS でアクセシビリティの許可を求められた場合

winwin がショートカットを受け取ってウィンドウを動かすには、アクセシビリティの許可が必要です。  
初めて起動したときに許可を求められたら「システム設定を開く」を押し、「アクセシビリティ」の一覧で winwin をオンにしてください。
オンにすると、起動し直さなくてもショートカットが使えるようになります。

## 使い方

タスクトレイアイコン(macOS ではメニューバーのアイコン)から設定画面が起動できます。  
設定画面で登録したショートカットを押下すると、アクティブなウィンドウが設定したサイズ・位置にリサイズされます。

macOS では、この説明の `Alt` を `Option`、`Win` を `Command` に読み替えてください。

### 配置の追加・変更

配置は「基準位置」「幅・高さ」の組み合わせで決まります。

- 基準位置: ウィンドウを画面のどこに寄せるか
- 幅・高さ: 画面に対する比率。`1/2` で半分、`1` で画面いっぱい。空欄にすると今のウィンドウの幅・高さのまま

たとえば幅を空欄、高さを `1/3`、基準位置を「左上」にすると、今の幅のまま左上に寄せて高さだけ画面の 1/3 にできます。

「フィット」をオンにすると、幅・高さの代わりに、基準位置の側の空きいっぱいに広げます。空きとはいちばん手前にあるウィンドウと重ならない場所です。動かすウィンドウと、常に最前面に表示されるウィンドウは数えません。

- 基準位置が「左」「右」なら高さは画面いっぱい、「上」「下」なら幅は画面いっぱいになります
- 四隅なら、角から手前のウィンドウにぶつかるところまで、横にも縦にも広げます。手前のウィンドウが画面の端に接している向きは、そのウィンドウと同じ幅・高さにそろえます。たとえば右下に幅 2/3・高さ 2/3 のウィンドウがあるとき、「左上」は幅 1/3・高さ 1/3、「左下」は幅 1/3・高さ 2/3、「右上」は幅 2/3・高さ 1/3 になり、「右下」は動きません
- 「中央」は選べません。基準位置の側に空きがなければ動きません

たとえば左上に置いたウィンドウの手前に右半分のウィンドウがあるとき、基準位置「左」のフィットでは左半分に広がります。基準位置「右」では空きがないので動きません。

### サイクルショートカット

同じショートカットに複数の配置を設定すると、一覧の上にあるものから順に適用されます。  
たとえば `Ctrl + Shift + ←` に対して「左半分」「左2/3」「左5/6」の設定を作成すると、 `Ctrl + Shift` を押したまま `←` を連打するたびにウィンドウが「左半分」→「左2/3」→「左5/6」→「左半分」→ … と順番に切り替わります。

### キーストロークショートカット

修飾キーを押したまま 2 つのキーを順に押す、キーストローク型のショートカットが登録できます。  
たとえば `Ctrl+Shift` を押したまま `← , ↑` と続けて押すような入力に対し、特定の配置を紐づけることができます。  

キーストロークはサイクルショートカットと併用できます。  
たとえば `Ctrl+Shift + ←,↑` に対して「左上 1/2 × 1/2」「左上 1/2 × 2/3」の2つを設定し、 `Ctrl+Shift` を押したまま `← , ↑ , ↑` と連続押下するとウィンドウは「左上 1/2 × 2/3」になります。

### リセット

設定画面の「動作」で「リセット」を選んだショートカットを押すと、winwin で配置したウィンドウが、最初に配置する前の位置・大きさに戻ります。Windows では、配置する前に最大化していたウィンドウは、最大化した状態に戻ります。

winwin で配置していないウィンドウには何も起きません。配置したあとに縁をドラッグして大きさを変えたウィンドウや、タイトルバーでドラッグして元の大きさに戻ったウィンドウも同じです。

### 保存する前に試す

「テスト用ウィンドウを開く」を押すと、設定中のコマンドを実際に試すことができます。  
設定変更しながら保存前に挙動を確かめたいときに使用してください。

### 設定を別の PC に移す

設定画面の「エクスポート...」で、ショートカットとテーマをファイルに書き出せます。
移したい PC の設定画面で「インポート...」からそのファイルを選ぶと、ショートカットとテーマがファイルの内容に置き換わります。「保存して閉じる」を押すと確定します。
Windows で書き出したファイルは Windows 版でだけ、macOS で書き出したファイルは macOS 版でだけ読み込めます。v0.20.1 以前の winwin で書き出したファイルは読み込めないので、書き出し直してください。「Windows へのサインイン時に winwin を起動する」(macOS では「ログイン時に winwin を起動する」)はファイルに含まれません。

### 終了する

Windows では通知領域のアイコンを右クリックし、「終了」を選びます。macOS ではメニューバーのアイコンをクリックし、「終了」を選びます。

### 更新・アンインストール

更新するときは、新しいバージョンのインストーラを実行してください。起動中の winwin は自動で終了し、上書きされます。  
設定はそのまま引き継がれます。

アンインストールは、Windows の「設定」→「アプリ」→「インストールされているアプリ」から winwin を選んで行います。

macOS で更新するときは、winwin を終了してから、新しい `.dmg` の `winwin.app` を「アプリケーション」フォルダへ入れて置き換え、
インストールのときと同じコマンドで隔離属性を外してください。設定はそのまま引き継がれます。  
0.19.0 以前から更新したときと、リリースノートで案内があったときは、更新のあとにショートカットが効かなくなります。一度だけ、「システム設定」→「プライバシーとセキュリティ」→「アクセシビリティ」の一覧で winwin を選んで「−」で削除し、winwin を起動し直して許可し直してください。

macOS でアンインストールするときは、winwin を終了してから「アプリケーション」フォルダの winwin をゴミ箱へ移します。
設定も消すときは、`~/Library/Application Support/winwin` フォルダを削除してください。

## 制限事項

- Windows: 管理者として実行されているウィンドウは、winwin も管理者として実行しているときにしか動かせません
- Windows: Windows や他のアプリケーションがすでに使っているショートカット(`Win + ←` など)は登録できません。登録できなかったものは起動時に通知でお知らせします
- アプリケーションによっては、最小サイズなどの都合で指定どおりの大きさにならないことがあります
- 自動アップデートはありません。更新するときは新しいインストーラを実行してください
- Windows の配布物はコード署名をしていません。macOS の配布物は公証をしていません
