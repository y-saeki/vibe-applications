# pecha-player

手持ちのスライドを PechaKucha(ペチャクチャ)形式で再生し、登壇の練習をするためのプレイヤーです。  
macOS / Windows 対応。

PechaKucha はスライド 20 枚をそれぞれ 20 秒ずつ、自動でめくりながら話すプレゼンテーションの形式です。

- PDF ファイルか Google スライドの URL を読み込むだけで、本番と同じ 20 秒×20 枚のリズムで練習できます
- 経過時間・何枚目か・次のスライドまでの残り時間を、画面の下のバーに表示します。どれも個別に隠せます
- 最後のスライドが終わるとシャッターが下り、何枚目・何秒まで話したかを表示します
- 非公開の Google スライドも Google にログインすれば読み込めます

## 動作環境

- macOS 11 以降 (Apple Silicon のみ)
- Windows 11 (x64 のみ)

## インストール

[Releases](https://github.com/y-saeki/vibe-applications/releases) の `pecha-player-v<version>` から、お使いの OS 向けのファイルをダウンロードしてください。

- macOS: `pecha-player_<version>_aarch64.dmg`
  - 開いて `pecha-player.app` を「アプリケーション」フォルダへ入れます
- Windows: `pecha-player_<version>_x64-setup.exe`
  - 実行するとインストーラが起動します。インストーラの案内に従ってください

### macOS で「壊れているため開けません」と表示される場合

コード署名・公証を行っていないため、ダウンロードした `.app` の実行は Gatekeeper に拒否されます。  
`.app` を「アプリケーション」フォルダに移したうえで、次のコマンドで隔離属性を外してください。

```sh
xattr -dr com.apple.quarantine /Applications/pecha-player.app
```

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

### Windows で「WindowsによってPCが保護されました」と表示される場合

コード署名を行っていないため、ダウンロードしたインストーラは SmartScreen に警告されます。  
「詳細情報」をクリックすると「実行」ボタンが出るので、押すとインストールを続けられます。

> [!CAUTION]
> この操作に不安を感じる場合、無理に実行せず、本アプリケーションの利用を避けてください。

## 使い方

### スライドを用意する

1 ページ目を表紙にして、その後ろに 20 枚のスライドを並べてください(合計 21 ページ)。  
表紙はスタート前の待機中に表示され、スタートを押すと 2 ページ目から数え始めます。21 ページを超えた分は再生しません。

### 読み込む

起動すると読み込みの画面が開きます。あとから別のスライドに替えるときは、左下の「読み込み」を押します。

- PDF ファイル: 「PDF を選ぶ…」で選ぶか、ウィンドウにドロップします
- Google スライド: ブラウザのアドレスバーか共有ダイアログの URL を貼り付けて「開く」を押します。ログインが必要なスライドでは「Google にログイン…」が表示されるので、開いたウィンドウでログインしてください。終わると自動で読み込みます

### 練習する

「スタート」を押すと 1 枚目に進み、以降 20 秒ごとにめくれます。20 枚目を 20 秒表示するとシャッターが下りて終了です。  
途中でやめるときは「ストップ」を押します。「もう一度」で表紙に戻ります。

| キー | 動作 |
|---|---|
| `Space` / `Return` | スタート、終了後は表紙に戻る |
| `Esc` | ストップ |
| `F` | フルスクリーンの切り替え |
| `⌘O` / `Ctrl+O` | スライドを読み込む |

フルスクリーンにすると、スライドが画面全体に表示されます。下のバーはしばらく操作しないと隠れ、マウスを画面の下端に近づけると戻ります。

練習中に `Space` を押してもストップしません。スライドを送るつもりで押して練習が終わってしまわないようにするためです。

## 制限事項

- 読み込めるのは PDF ファイルと Google スライドの URL だけです。PowerPoint のファイルは PDF に書き出してから読み込んでください
- パスワードのかかった PDF は開けません
- 読み込めるファイルは 300 MB までです
- スライドのアニメーションや動画は再生されません。各ページの見た目がそのまま表示されます
- 1 枚あたりの時間は 20 秒で固定です
